Wat is een token?

Een interactieve uitleg over hoe LLMs tekst opbreken in tokens.

Tekst → Tokens → Modellen

Een LLM leest geen woorden zoals jij of ik. Het ziet tekst als een reeks tokens — nummers die stukjes tekst vertegenwoordigen.

Een token is meestal zo lang als een woord, maar kan ook korter zijn: een deel van een lang woord, een leesteken, of zelfs een spatie. Engels gemiddeld: 1 token ≈ 4 lettertekens. Nederlands loopt iets dichter omdat woorden korter zijn.

Voorbeeld: "AI is cool" = 4 tokens
"🤖" (één emoji) kan 1 tot 4 tokens zijn, afhankelijk van het model.

Waarom moet je dit weten?

  • Aantallen: LLMs werken met token-limieten (context window). GPT-4o: 128K tokens, dat is ≈ 300 pagina's A4.
  • Prijs: Providers rekenen per token — meer tekst = meer kosten.
  • Kwaliteit: Hoe een woord getokeniseerd wordt, beïnvloedt hoe goed het model het begrijpt.

Elk model heeft een eigen tokenizer

Niet alle LLMs breken tekst op dezelfde manier op. De tokenizer van GPT-4 verschilt van die van Claude of Llama. Dat betekent dat dezelfde zin in verschillende modellen een ander aantal tokens kan geven.

GPT (cl100k_base)
~4 tekens per token
Claude (ClaudeTokenizer)
~3.5 tekens per token
Llama 3
~3.8 tekens per token
